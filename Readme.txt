============================================================
                    REIKONTER
          Aplikasi Kasir & Manajemen Toko
============================================================


1. FITUR UTAMA
------------------------------------------------------------

- Login pengguna dengan sistem role
- Dashboard Administrator
- Point of Sale (POS)
- Manajemen produk
- Manajemen kategori
- Manajemen stok
- Pencatatan transaksi
- Riwayat transaksi
- Pencatatan pengeluaran
- Backup dan restore database
- Export data transaksi ke CSV
- Database SQLite lokal
- Aplikasi desktop Windows (.exe)


2. ROLE PENGGUNA
------------------------------------------------------------

ADMINISTRATOR
-------------
Administrator memiliki akses untuk mengelola data produk,
kategori, stok, transaksi, pengeluaran, backup database,
serta fitur administratif lainnya.

KASIR
-----
Kasir memiliki akses terhadap fitur Point of Sale (POS)
untuk melakukan proses transaksi penjualan.
